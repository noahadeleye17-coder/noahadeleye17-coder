## 🚀 Featured Projects

### 🏠 [Off-Campus Hub](https://offcampushub.ng)
Connects FUTA students with off-campus housing and roommate matches.

- 🏠 Listings directory with server-side search & pagination
- 🤝 Roommate matching with compatibility scoring
- 📍 Map-based discovery (Leaflet + geocoding)
- 🔐 JWT + Google OAuth authentication
- 📱 Installable PWA

### 🛍️ [ShopLink — Vendor Storefront](https://github.com/noahadeleye17-coder/Vendor-storefront)
A WhatsApp-native storefront platform. Vendors get a shareable link; customers browse and order with a single tap into WhatsApp — no accounts, no app installs, no forms.

- 🔗 One shareable storefront link per vendor
- 💬 Direct-to-WhatsApp ordering flow
- ⚡ Zero friction — no sign-up required for customers
